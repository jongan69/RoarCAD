# Build specification

The canonical `BoardProject` is Zod-validated and revisioned by SHA-256. `@tscircuit/core` generates Circuit JSON; viewers render it; checks gate fabrication; converter packages generate Gerber and placement files. A native browser worker runs the shared compiler and builds the exact-MPN BOM and artifact manifest without blocking page interaction. Four `document.modelContext.registerTool` calls wrap the same React actions; only the visible approval control applies previews. Native Netlify and Vercel functions share the same JLCPCB trust boundary. See `docs/NETLIFY_RELEASE.md` for deployment evidence and remaining gates.
